Used when a phrase has no translation in the chosen language. A missing phrase falls back rather than rendering its key, which is what a person would otherwise see on the page.

Translation files

One JSON file per language under lang/, named by its code — lang/id.json for Bahasa Indonesia. A language with no file falls back, so adding one is the whole of adding a language.
